# PixelCraft Studio

純前端瀏覽器批次影像處理工作室，使用 React、TypeScript、Vite 與 HTML5 Canvas 實作，所有影像運算皆於本地瀏覽器完成。

## 功能特色

- **裁切與尺寸調整**：90° 旋轉、水平/垂直翻轉、比例預設（自由、`1:1`、`4:3`、`16:9`、`9:16`、`4:5`）、互動式三分線裁切框、套用裁切比例至全部圖片，以及原尺寸 / 百分比縮放 / 指定寬高像素輸出。
- **即時調色與濾鏡**：內建 6 種快速風格濾鏡（原圖、鮮明、黑白底片、復古暖陽、冷調青影、柔焦夢幻），並支援亮度、對比度、飽和度、色相偏移、黑白、復古與高斯模糊微調。
- **文字 / 圖片浮水印**：支援自訂文字（大小、顏色、粗體、斜體）與透明 PNG Logo 上傳，提供九宮格對齊與滿版平鋪模式，可調整透明度、旋轉角度與邊界距離。
- **對比與批次匯出**：支援「按住檢視原圖」比對、輸出格式切換（WebP / JPG / PNG）、預估檔案大小顯示，以及單張下載與 `JSZip` 批次打包下載。

## 開發與執行

```powershell
# 安裝套件
npm.cmd install

# 啟動開發伺服器
npm.cmd run dev

# 執行單元測試
node --test src/engine/imageProcessor.test.ts

# 靜態檢查與正式建置
npm.cmd run lint
npm.cmd run build
```
